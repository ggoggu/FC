# FC 프로젝트 기능별 프롬프트 예시

본 문서는 FC 프로젝트의 **멀티플레이/단독 플레이 100% 호환 아키텍처**와 **모듈형 도메인 규칙**에 맞춘 실전 프롬프트 템플릿 모음입니다.

---

## 1. 일반 게임플레이 컴포넌트 구현

> **용도**: 일반 이동, 상호작용, 타이머 기반 자원, 액션 로직 등 표준 C++ 컴포넌트로 구현할 때

```text
캐릭터의 [스태미나 및 대시(Dash)] 기능을 구현해줘.

1. 명세 요구사항:
   - 클래스: UFCStaminaComponent : public UActorComponent (Source/FC/Public/Character/FCStaminaComponent.h)
   - 변수: CurrentStamina, MaxStamina, StaminaDrainRate, StaminaRegenRate
   - 리플리케이션: CurrentStamina는 ReplicatedUsing = OnRep_CurrentStamina로 동기화 (COND_OwnerOnly).

2. 멀티플레이 및 UI 규칙:
   - 대시 요청 시 Server_RequestDash() RPC(WithValidation 포함)를 통해 서버 권한으로 스태미나 차감 및 속도 적용.
   - UI는 OnStaminaChanged 델리게이트를 브로드캐스트하여 분리(Slate/UMG 헤더 직접 참조 금지).

3. 검증 지시:
   - 작성 후 정적 검증 파이프라인(python Scripts/pipeline.py static)을 실행해 리플리케이션 및 대역폭 조건을 점검해줘.
```

---

## 2. GAS 기반 어트리뷰트 및 스킬 구현

> **용도**: GAS(Gameplay Ability System)를 활용한 복잡한 상태이상(Buffs/Debuffs), 태그 기반 상호작용, 이펙트 중첩, 콤보 스킬 등을 구현할 때

```text
GAS 기반의 [분노(Rage) 및 강타 스킬] 시스템을 구현해줘.

1. 명세 요구사항:
   - 어트리뷰트 셋: UFCCombatAttributeSet (Source/FC/Public/AbilitySystem/FCCombatAttributeSet.h)
   - 어트리뷰트: Rage, MaxRage
   - 어빌리티: UGA_HeavyStrike (Rage 20 소모)
   - 태그: `Ability.Skill.HeavyStrike`, `State.Buff.Enraged`

2. GAS 아키텍처 규칙:
   - .antigravity/rules/04-gameplay-ability-system.md 표준 준수.
   - ATTRIBUTE_ACCESSORS 매크로 선언 및 OnRep_* 콜백에서 GAMEPLAYATTRIBUTE_REPNOTIFY 적용.
   - PreAttributeChange에서 0 ~ MaxRage 클램핑 로직 구현.
   - 피격/시각 효과는 Multicast RPC 대신 Gameplay Cue(UGameplayCueNotify_*)를 활용.

3. 검증 지시:
   - 코드 작성 후 정적 검증 파이프라인(python Scripts/pipeline.py static)을 실행하여 매크로 및 규칙 준수를 확인해줘.
```

---

## 3. Fast Array Serialization 기반 인벤토리 / 무기 슬롯

> **용도**: 동적 장비 목록, 아이템 슬롯, 룬 슬롯 등 잦은 변경이 일어나는 컨테이너 동기화

```text
Fast Array Serialization을 적용한 [장비/무기 슬롯] 시스템을 구현해줘.

1. 명세 요구사항:
   - .antigravity/rules/05-combat-and-inventory-networking.md 표준 준수.
   - 구조체: FFCWeaponEntry (FFastArraySerializerItem 상속), FFCWeaponList (FFastArraySerializer 상속)
   - 컴포넌트: UFCWeaponManagerComponent (Source/FC/Public/Inventory/FCWeaponManagerComponent.h)
   - 델타 동기화: NetDeltaSerialize 구현 및 PostReplicatedAdd / PreReplicatedRemove 콜백 지원.

2. 대역폭 및 UI 규칙:
   - 단순 TArray 복제 금지 (반드시 FFastArraySerializer 준수).
   - 무기 목록 동기화는 소유 클라이언트에게만 전달(COND_OwnerOnly).
   - OnWeaponListUpdated 델리게이트를 통해 UI와 완전 분리.

3. 검증 지시:
   - 정적 검증 파이프라인(python Scripts/pipeline.py static)을 실행해 대역폭 규칙을 검증해줘.
```

## 4. 멀티플레이어 상호작용 (Interaction) 컴포넌트

```text
월드 아이템 상호작용을 위한 UFCInteractionComponent를 구현해줘.

1. 명세 요구사항:
   - 클래스: UFCInteractionComponent : public UActorComponent (Source/FC/Public/Interaction/FCInteractionComponent.h)
   - 인터페이스: IFCInteractableInterface
   - 로직 분리:
     * 클라이언트: 카메라 기준 로컬 레이캐스트로 대상 탐색 후 상호작용 입력.
     * 서버 RPC: Server_InteractWith(AActor* TargetActor) (WithValidation 필수).
     * 서버 권한: 캐릭터와 대상 간 거리(MaxInteractionDistance)를 서버에서 엄격히 검증 후 인터페이스 Interact() 호출.

2. UI 분리:
   - 서버 코드에 UMG 헤더 포함 금지. FOnInteractableFound 델리게이트로 UI 표시 이벤트 전달.

3. 검증 지시:
   - 작성 후 python Scripts/pipeline.py static 및 python Scripts/pipeline.py build를 순차 실행해줘.
```

## 5. 전투 밸런스 및 TTK 시뮬레이션 튜닝

```text
[대검(Greatsword) 및 단검(Dagger)]의 전투 밸런스 수치를 튜닝해줘.

1. 목표 밸런스 기준:
   - 무장 티어: Unarmored (체력 100, 방어 0), Medium (체력 150, 방어 50), Heavy (체력 200, 방어 100)
   - 목표 TTK: 
     * 단검: 무장 대상 1.2초 내외, 중갑 대상 3.5초 내외
     * 대검: 무장 대상 1.0초(단타 위주), 중갑 대상 2.5초 내외

2. 밸런스 파이프라인 지시:
   - python Scripts/pipeline.py balance를 실행하여 현재 DPS 및 TTK 수치를 파악해줘.
   - 목표 수치에 맞게 기본 대미지, 공속, 방어 관통력 수치를 조정한 후 결과를 요약 보고해줘.
```

## 6. 버그 수정 및 컴파일 에러 해결

```text
현재 프로젝트에서 발생하는 빌드 및 리플리케이션 문제를 점검하고 해결해줘.

1. 작업 내용:
   - python Scripts/pipeline.py build를 실행하여 UBT 컴파일 에러와 원본 파일:라인 위치를 확인.
   - 에러가 발생한 원인을 파악하여 C++ 코드를 자가 수정.
   - 수정 완료 후 python Scripts/pipeline.py static을 실행해 리플리케이션 누락이 없는지 2차 확인.
   - 수정된 내용의 핵심 diff 요약만 간결하게 설명해줘.
```
