# FC 프로젝트 기능별 프롬프트 예시

본 문서는 FC 프로젝트의 **멀티플레이/단독 플레이 100% 호환 아키텍처**와 **GAS / Fast Array 규칙**에 부합하는 실전 프롬프트 템플릿 모음입니다.

---

## 1. 신규 GAS 어트리뷰트 및 어빌리티 구현

```text
GAS 기반의 [스태미나(Stamina)] 시스템을 구현해줘.

1. 명세 요구사항:
   - 어트리뷰트 셋: UFCCombatAttributeSet (Source/FC/Public/AbilitySystem/FCCombatAttributeSet.h)
   - 어트리뷰트: Stamina, MaxStamina
   - 어빌리티: UGA_Sprint, UGA_Dodge
   - 태그: `Ability.Action.Sprint`, `State.Debuff.Exhausted`

2. 아키텍처 규칙:
   - ATTRIBUTE_ACCESSORS 매크로 선언 및 OnRep_* 콜백에서 GAMEPLAYATTRIBUTE_REPNOTIFY 준수.
   - GetLifetimeReplicatedProps에 DOREPLIFETIME_CONDITION_NOTIFY(COND_None, REPNOTIFY_Always) 등록.
   - PreAttributeChange에서 0 ~ MaxStamina 클램핑 로직 구현.
   - 시각 효과(달리기 먼지/VFX)는 Multicast RPC 대신 Gameplay Cue(UGameplayCueNotify_*)를 활용.

3. 검증 지시:
   - 코드 작성 후 정적 검증 파이프라인(python Scripts/pipeline.py static)을 실행하여 GAS 매크로 및 규칙 준수를 확인해줘.
```

---

## 2. Fast Array Serialization 기반 인벤토리 / 무기 슬롯

```text
Fast Array Serialization을 적용한 [장비/무기 슬롯] 시스템을 구현해줘.

1. 명세 요구사항:
   - 구조체: FFCWeaponEntry (FFastArraySerializerItem 상속), FFCWeaponList (FFastArraySerializer 상속)
   - 컴포넌트: UFCWeaponManagerComponent (Source/FC/Public/Inventory/FCWeaponManagerComponent.h)
   - 델타 동기화: NetDeltaSerialize 구현 및 PostReplicatedAdd / PreReplicatedRemove 지원.

2. 네트워크 및 대역폭 규칙:
   - 단순 TArray 복제 금지 (반드시 FFastArraySerializer 준수).
   - 무기 슬롯 목록은 소유 클라이언트에게만 복제(COND_OwnerOnly).
   - UI 위젯 코드를 컴포넌트에 직접 include하지 말고, OnWeaponListUpdated 델리게이트를 통해 분리.

3. 검증 지시:
   - 정적 검증 파이프라인(python Scripts/pipeline.py static)을 실행해 대역폭 및 리플리케이션 규칙을 검증해줘.
```

## 3. 멀티플레이어 상호작용 (Interaction) 컴포넌트

```text
월드 아이템 상호작용을 위한 UFCInteractionComponent를 구현해줘.

1. 명세 요구사항:
   - 클래스: UFCInteractionComponent : public UActorComponent (Source/FC/Public/Interaction/FCInteractionComponent.h)
   - 인터페이스: IFCInteractableInterface
   - 핵심 로직:
     * 클라이언트: 카메라 기준 로컬 레이캐스트로 대상 탐색 후 상호작용 키 입력 처리.
     * 서버 RPC: Server_InteractWith(AActor* TargetActor) (WithValidation 필수).
     * 서버 권한: 캐릭터와 대상 간 거리(MaxInteractionDistance)를 서버에서 엄격히 검증 후 인터페이스 Interact() 호출.

2. 권한 및 UI 분리:
   - 서버 코드에 Slate/UMG 위젯 헤더 포함 금지.
   - 상호작용 가능 대상 감지 시 FOnInteractableFound 델리게이트로 브로드캐스트하여 UI가 감지하도록 설계.

3. 검증 지시:
   - 코드 작성 후 정적 검증(pipeline.py static) 및 빌드(pipeline.py build)를 순차 실행해줘.
```

## 4. 전투 밸런스 및 TTK 시뮬레이션 튜닝

```text
[대검(Greatsword) 및 단검(Dagger)]의 전투 밸런스 수치를 튜닝해줘.

1. 목표 밸런스 기준:
   - 무장 티어: Unarmored (체력 100, 방어 0), Medium (체력 150, 방어 50), Heavy (체력 200, 방어 100)
   - 목표 TTK: 
     * 단검: 무장 대상 1.2초 내외, 중갑 대상 3.5초 내외
     * 대검: 무장 대상 1.0초(단타 위주), 중갑 대상 2.5초 내외

2. 밸런스 파이프라인 지시:
   - python Scripts/pipeline.py balance를 실행하여 현재 DPS 및 TTK 수치를 파악해줘.
   - 목표 수치에 맞게 기본 대미지, 공속, 방어 관통력 수치를 조정한 후 결과를 요약 보고해줘.
```

## 5. 버그 수정 및 컴파일 에러 해결

```text
현재 프로젝트에서 발생하는 빌드 및 리플리케이션 문제를 점검하고 해결해줘.

1. 작업 내용:
   - python Scripts/pipeline.py build를 실행하여 UBT 컴파일 에러와 원본 파일:라인 위치를 확인.
   - 에러가 발생한 원인을 파악하여 C++ 코드를 자가 수정.
   - 수정 완료 후 python Scripts/pipeline.py static을 실행해 매크로/리플리케이션 누락이 없는지 2차 확인.
   - 수정된 내용의 핵심 diff 요약만 간결하게 설명해줘.
```
